# AVACON Website Redesign

A modern, responsive redesign concept of the AVACON corporate website.

This project was created independently as a portfolio project after discovering the **Web Development Engineer (Volunteer)** opportunity at AvaCon. The goal was to demonstrate my front-end development skills by creating a clean, modern, and user-friendly website while preserving the company's professional identity.

> **Disclaimer:**
> This project is an independent redesign concept and was not commissioned, requested, or endorsed by AvaCon. It is intended solely for educational and portfolio purposes.
